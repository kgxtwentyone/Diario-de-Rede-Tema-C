# Diário de Rede (Tema C)

Aplicação Android desenvolvida para registo de notas com monitorização em tempo real do estado da rede e atribuição automática de carimbo de data e hora (timestamp).

## 👥 Membros do Grupo
* Integrante  (Kennedy Gilberto Davuca,202401144)


## 🚀 Funcionalidades Técnicas
* **ConstraintLayout:** Interface responsiva e estruturada.
* **Multi-Activity:** Navegação entre a tela principal (`MainActivity`) e a tela de criação (`NoteActivity`).
* **Monitorização de Rede:** Deteção do estado da ligação (Wi-Fi / Dados Móveis / Sem Conexão).
* **Registo Automático:** Anexação automática de data, hora e tipo de rede a cada nota criada.
* **Exibição Dinâmica:** Apresentação dos registos organizados através de uma `ListView`.
